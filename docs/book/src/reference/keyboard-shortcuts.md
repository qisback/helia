# Keyboard shortcuts

The desktop app's shortcuts, in one place.

| Keys | Action |
|---|---|
| Ctrl+O | Open a capture |
| Ctrl+E | Export the result |
| Left, Right | Previous or next frame (in the Time-lapse step, of the series) |
| Shift+Left, Shift+Right | Ten frames back or forward |
| Home, End | First or last frame |
| Space | Switch between the frame and the stacked result; in the Time-lapse step, play or pause |
| F1 | Open or close the About page (Esc also closes it) |
| Tab, Shift+Tab | Move between controls |

The arrow keys and Space act on the viewer when no control has keyboard focus.

## In the tone curve plot (Adjust step)

Click the plot, or Tab to it, then:

| Keys | Action |
|---|---|
| [ and ] | Choose the previous or next point |
| Arrow keys | Nudge the chosen point by 0.005 |
| Shift+arrow keys | Nudge it by 0.05 |
| Delete, Backspace | Remove the chosen point (not the end points) |

## With the mouse

| Action | Effect |
|---|---|
| Scroll over the picture | Zoom around the pointer |
| Drag the picture | Pan |
| Double-click the picture | Fit it to the window |
| Click the zoom readout | Fit it to the window |
| Click the quality curve | Jump to that frame |
| Drag the frame scrubber | Move through the capture |
| Click empty space in the tone curve plot | Add a curve point |
| Drag a curve point | Move it (it stops at its neighbours) |
| Double-click or right-click a curve point | Remove it |
| Drag a file onto the window | Open it |

## Accessibility

Every control has an accessible name and a tooltip, and the window works with
screen readers through AccessKit. Progress notices announce the stage, the
percentage and the time left in words.
